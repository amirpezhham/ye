# انتقال محتوای سایت به وردپرس

اسکریپت `npm run export:content` محتوای دیتابیس را به سه فایل تبدیل می‌کند:

```bash
npm run export:content -- --base-url=https://yedood2dood.ir
```

خروجی در پوشهٔ `exports/` (در `.gitignore` است) ساخته می‌شود:

| فایل | کاربرد | نحوهٔ درون‌ریزی در وردپرس |
|---|---|---|
| `site-content.json` | همهٔ داده‌ها (پشتیبان‌گیری یا مصرف با کد) | وردپرس **مستقیماً** این را نمی‌خورد (بخش ۳) |
| `woocommerce-products.csv` | محصولات | ووکامرس → محصولات → درون‌ریزی (ابزار بومی) |
| `wordpress-posts.xml` | مطالب وبلاگ (فرمت WXR) | ابزارها → درون‌ریزی → WordPress |

> ⚠️ **مهم‌ترین نکته:** وردپرس فایل JSON را به‌عنوان ورودی نمی‌شناسد. فرمت بومی‌اش برای محصولات **CSV** و برای مطالب **WXR (XML)** است. JSON فقط با افزونه‌های پولی (مثل WP All Import) یا کد اختصاصی قابل درون‌ریزی است.

---

## ۱. پیش‌نیازها

- روی وردپرس، افزونهٔ **WooCommerce** نصب و فعال باشد.
- `--base-url` را بدهید تا تصاویر **آدرس مطلق** بگیرند؛ وردپرس تصویر را از روی URL **دانلود** می‌کند و آدرس نسبی کار نمی‌کند.
- سایت مبدأ (یا فایل‌های تصویر) باید برای وردپرس قابل دسترس باشد. تصاویر استاتیک نمونه در `public/images/...` هستند و باید همراه سایت منتشر شوند یا دستی آپلود گردند.
- متغیر `DATABASE_URL` باید در `.env` تنظیم باشد (همان تنظیمات backend؛ به `docs/backend-setup.md` نگاه کنید).

---

## ۲. درون‌ریزی محصولات (ووکامرس)

1. وردپرس → **محصولات** → **درون‌ریزی**
2. فایل `woocommerce-products.csv` را انتخاب و آپلود کنید
3. ستون‌ها را نگاشت (map) کنید — نام‌ها از قبل با ستون‌های ووکامرس یکسان‌اند
4. گزینهٔ «دانلود و درج تصاویر» را روشن بگذارید
5. اجرا کنید

ستون‌های تولیدشده: `Type, SKU, Name, Published, Is featured?, Visibility in catalog, Short description, Description, In stock?, Stock, Regular price, Sale price, Categories, Images`

> فایل با **BOM** ذخیره می‌شود تا متن فارسی در اکسل و ووکامرس درست خوانده شود.

---

## ۳. درون‌ریزی مطالب وبلاگ

1. وردپرس → **ابزارها** → **درون‌ریزی** → **WordPress**
2. افزونهٔ «WordPress Importer» را نصب کنید
3. فایل `wordpress-posts.xml` را انتخاب و اجرا کنید

---

## ۴. اگر می‌خواهید از JSON استفاده کنید

سه راه دارید:

1. **افزونه:** WP All Import قابلیت خواندن JSON دارد (نسخهٔ رایگان محدود است). باید فایل را روی یک URL عمومی بگذارید و آن را به‌عنوان منبع JSON معرفی کنید.
2. **REST API وردپرس:** با اسکریپت دلخواه، هر محصول را با `POST /wp-json/wc/v3/products` (با کلید Consumer) بسازید. این روش برای انتقال کامل و بدون محدودیت CSV بهترین است.
3. **دستی:** چون تعداد محصولات زیاد نیست، `site-content.json` را باز کنید و مقادیر را کپی کنید.

---

## ۵. نکات مهم دربارهٔ داده‌ها

- **سفارش‌ها صادر نمی‌شوند.** جدول `orders` شامل نام، تلفن و نشانی مشتریان است (دادهٔ شخصی) و آگاهانه از خروجی حذف شده. اگر لازم دارید، خودتان کوئری بگیرید و مسئولیت نگهداری‌اش را در نظر بگیرید.
- **دسته‌بندی‌ها** در ستون `Categories` فایل CSV می‌آیند و ووکامرس خودش می‌سازد.
- **تصاویر محصولات** در حال حاضر یا مسیرهای استاتیک `public/images/products/...` هستند یا (اگر از پنل ادمین آپلود شده باشند) dataURL در دیتابیس. برای انتقال، تصاویر استاتیک باید روی هاست منتشر شوند تا وردپرس بتواند آن‌ها را دانلود کند؛ انتقال کامل تصاویر آپلودی به فضای ذخیره‌سازی پایدار جزو کارهای پیش از launch است.
